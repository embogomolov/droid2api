Automatic proxy blocking

🎯 Multi-tier key pools

💡 Use keys from pools in priority order, for example: free-tier pool, then primary pool.

💡 Switch to a lower-priority pool when the higher-priority pool has no usable keys left.

🔥 How do multi-tier pools work?
1️⃣ On the Dashboard tab, click "Create pool" and create pools with different priorities.
2️⃣ On the Keys tab, assign keys to the pools.
3️⃣ Enable this feature to prefer keys from higher-priority pools.
📖 Documentation: docs/MULTI_TIER_POOL.md

🗄️

Redis cache

💡 Default: 6379

💡 Avoid key name collisions

🖥️

Cluster mode

💡 Use multiple CPU cores for very high concurrency. Requires a restart.

💡 0 = detect CPU core count automatically. Recommended: 0.

⚠️ Notes:
• Changes to Redis and cluster mode settings require a server restart.
• Each worker runs independently in cluster mode.
• Test in development before deploying to production.
